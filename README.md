# Documentation : Exécution du projet

## Prérequis

- **Node.js** (version recommandée : 22)
- **npm** (généralement installé avec Node.js)

## Comment executer

1. Installer les dépendances :

    ```bash
    npm install
    ```

2. Creer l'executable
    ```bash
    npm link
    ```

3. Lancer l'application :

    ```bash
    acdmp run <chemin vers le fichier zip>
    ```

### Exemple de flow

- cloner le depot
- aller dans le dossier du projet avec la commande `cd test-acdmp-mahery`
- executer la commande `npm install`
- execuer la commande `npm link`
- executer la commande `acdmp run Dossier_Test_ACDMP.zip`
